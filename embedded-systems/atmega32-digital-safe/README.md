# ATmega32 Digital Safe

**Embedded C · ATmega32 · Matrix Keypad · LCD**

## Academic context
- Course: Microprocessors
- Term 4001
- Instructor: Dr. Mojtaba Asgari

## Project
A password-controlled digital-safe project based on an ATmega32, a 4×4 matrix keypad, and a character LCD.

## Implemented concepts
- Matrix-keypad scanning
- Password entry and comparison
- LCD feedback
- Locked/open state logic

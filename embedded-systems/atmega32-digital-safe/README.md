# ATmega32 Digital Safe

**Embedded C · ATmega32 · Matrix Keypad · LCD**

A password-controlled digital-safe project using keypad scanning, password logic, LCD feedback, and locked/open state handling.

[**Open Project Demo**](https://soroushhaghi.github.io/bachelor-engineering-projects/digital-safe/)

## What it demonstrates
- 4×4 matrix-keypad scanning
- Password entry and comparison
- LCD messaging
- Locked/open state logic
